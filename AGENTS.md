# WordPress article workflow

When asked to update the druding.com Arduino controller article (post 725), always download a fresh copy from WordPress before making changes. Preserve direct WordPress edits. Save raw Gutenberg markup and metadata in `Documents/WordPress/post.html` and `Documents/WordPress/post.json` and commit incoming changes before editing. After publishing authorized edits, fetch and commit the saved result. Follow `Documents/WordPress/README.md`. Do not stage unrelated changes or push unless requested.
